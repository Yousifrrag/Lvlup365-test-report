BUG-002 Concurrent Login — Force Logout on Device 1 Medium

When a user logs in from Device #2 while still authenticated on Device #1, the system allows the second login and automatically force-logs-out Device #1.

Needs confirmation: is single-session enforcement the intended design, or should concurrent sessions be allowed?

Steps to Reproduce
  1. Log in with User ID 10453 on Mobile #1.
  2. Without logging out, log in with the same credentials on Mobile #2.
  3. Mobile #2 authenticates successfully.
  4. Mobile #1 is force-logged out.
